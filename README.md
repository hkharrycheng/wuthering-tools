# 鳴潮助手 | HIS Tools

鳴潮遊戲數據管理工具，從飛書多維表格讀取共鳴者POOL、抽卡成本、配隊成員、奇點擴張階級榜。

## 功能

- 🎭 **共鳴者POOL**：圖庫式展示所有擁有共鳴者，支援屬性Filter、排序（星級/成本/名稱/入手日期）
- 🏆 **奇點擴張排名**：按最佳分數由高至低排列，頭三名金銀銅特效
- 📊 **詳細資訊**：點擊共鳴者查看畢業面板、抽卡記錄、出場配隊
- 👹 **Boss資料**：排名卡詳情顯示Boss縮圖、備註、第一輪/第二輪啟用
